# 로드셀(Load Cell) 테스트 가이드 — PhidgetBridge 4-Input (1046_0)

> 대상 장비: **PhidgetBridge 4-Input (모델 1046_0, 보드 리비전 1046_0B)**
> 인터페이스: USB(Mini-USB) · API 객체: `VoltageRatioInput` · 채널 0~3 (최대 4개 로드셀 동시 측정)
> 출처: Phidgets 제품 페이지 prodid=1027 / User Guide 탭
> 작성일: 2026-06-23

---

## 0. 한눈에 보기

PhidgetBridge 1046은 로드셀·스트레인게이지·휘트스톤 브리지 센서의 미세 신호를 증폭해 USB로 디지털 값을 읽어주는 인터페이스다. 측정값은 **전압비(V/V, 정확히는 mV/V)** 단위로 보고되며, 무게·힘 단위(g, N 등)로 환산하려면 **캘리브레이션**이 필요하다.

핵심 사양 요약:

| 항목 | 값 |
|---|---|
| 브리지 입력 채널 | 4개 (채널 0~3) |
| ADC 분해능 | 24-bit |
| 최대 샘플레이트 | 122 samples/s (채널 수 무관) |
| 게인(Gain) 설정 | 1, 8, 16, 32, 64, 128 |
| 연결 방식 | USB Mini-B (HID 스택) |
| 드라이버 | Phidget22 (권장), Phidget21 |
| 권장 배선 굵기 | 16~26 AWG |
| 동작 온도 | 0 ~ 70 °C |
| 최대 브리지 전류 | 465 mA |

> ⚠️ 참고: 1046_0은 **NRND(신규 설계 비권장)** 상태다. 신규 프로젝트라면 후속 모델 1046_1(prodid=1270) 또는 VINT 방식 DAQ1500_0(prodid=957)도 검토할 것. 기존 시스템 대체용으로는 그대로 사용 가능.

## 1. 테스트 준비물

- PhidgetBridge 1046 보드 1개
- USB 케이블 (Mini-B) + 컴퓨터
- 테스트할 로드셀(또는 휘트스톤 브리지 센서) — 1~4개
- (선택) 캘리브레이션용 기준 분동(known weight) 2개 이상
- (선택) 멀티미터 — 배선 정보가 없는 센서의 핀 확인용

## 2. 소프트웨어 설치 (OS별)

### Windows
1. 시스템 비트 확인: `⊞ Win + Pause/Break`
2. Phidgets 라이브러리 다운로드 후 설치
   - 64비트: `Phidget22-x64.exe`
   - 32비트: `Phidget22-x86.exe`
3. 설치 마법사: Run → Next → 라이선스 동의 → 설치 경로 선택 → Confirm → 완료 후 Close

### macOS
1. OS 버전에 맞는 패키지 다운로드
   - macOS 10.11 이상: `Phidget22.dmg`
   - macOS 10.7~10.10: `Phidget22_OS_X_10_7.dmg`
   - macOS 10.5~10.6: `Phidget22_OS_X_10_5.dmg`
2. `Phidgets.pkg` 더블클릭 → Continue → Agree → Install → 계정 비밀번호 입력
3. 확장 프로그램이 차단되면: **Open Security Preferences** → Phidgets Inc 항목 **Allow** → Close

### Linux
```bash
sudo apt-get install libusb-1.0-0-dev gcc make
# libphidget22 다운로드 후 압축 해제, 폴더 진입
./configure
make
sudo make install
```
(선택 패키지: phidget22networkserver, phidget22admin, libphidget22extra, libphidget22java)

## 3. 하드웨어 연결 (배선)

### 3.1 기본 연결 순서
1. USB 케이블을 컴퓨터와 PhidgetBridge에 연결
2. 로드셀(휘트스톤 브리지 센서)을 보드 터미널 블록에 연결

### 3.2 터미널 단자 구성 (채널당)
각 채널은 **`5V` · `G` · `+` · `−`** 단자로 구성된다.
- `5V`, `G`: 센서 여기(excitation) 전원 — 브리지에 전압 공급
- `+`, `−`: 차동 신호(differential) 입력 — 센서 출력 측정

### 3.3 데이터시트가 있는 경우
센서 사양서의 배선 색상 규약에 따라 연결:
- 여기 전원 라인(EXC+ / EXC−) → `5V` / `G`
- 신호 라인(SIG+ / SIG−) → `+` / `−`

### 3.4 데이터시트가 없는 경우 (멀티미터로 핀 판별)
센서 내부에 전자회로가 없는 순수 브리지라면 멀티미터로 결선을 찾을 수 있다.
1. 4개 선 사이 저항을 모두 측정 (총 6개 조합)
2. 6개 중 **2개 조합이 나머지보다 20~40% 높은 저항**을 보인다
3. 이 고저항 조합 중 하나를 골라 `5V`와 `G`에 연결 (여기 전원)
4. 남은 2개 선을 `+` / `−`에 연결 (신호)
5. 하중을 가했을 때 V/V 값이 **예상과 반대로 변하면** `+`/`−`를 서로 바꿔 연결

### 3.5 배선 시 주의사항
- 1046에서 센서까지의 **모든 선은 길이·굵기를 동일하게** 할 것. 온도 변화에 따른 전선 저항 변화가 서로 상쇄되어 오차가 줄어든다.
- 사용하지 않는 채널은 전원을 끌 수 있어 소비전력과 센서 발열(오차 요인)을 줄일 수 있다.

## 4. 동작 확인 (Verify)

### Windows / macOS
1. **Phidget Control Panel** 실행 (작업표시줄/메뉴바의 Phidget 아이콘 더블클릭)
2. 연결된 Phidget 목록에 1046이 표시되는지 확인
3. 해당 채널의 **"Bridge Input"** (= Voltage Ratio Input)을 더블클릭하면 실시간 측정값 확인
4. 손으로 로드셀에 하중을 가했을 때 V/V 값이 변하는지 확인 (그래프·로깅은 Windows Control Panel에서 지원)

### Linux
HelloWorld C 예제로 연결 검증:
```bash
gcc HelloWorld.c -o HelloWorld -lphidget22
sudo ./HelloWorld
```
> USB 접근을 위해 `sudo`로 실행하거나 udev 규칙을 설정해야 한다.

## 5. 게인(Gain) 설정

측정 전 게인을 정하는 것이 중요하다. **센서 전체 범위를 측정할 수 있는 가장 높은 게인**을 선택하면 분해능이 좋아진다.

| Gain | 분해능(Resolution) | 측정 범위(Range) |
|---|---|---|
| 1 | 119 nV/V | ± 1000 mV/V |
| 8 | 14.9 nV/V | ± 125 mV/V |
| 16 | 7.45 nV/V | ± 62.5 mV/V |
| 32 | 3.72 nV/V | ± 31.25 mV/V |
| 64 | 1.86 nV/V | ± 15.625 mV/V |
| 128 | 0.93 nV/V | ± 7.8125 mV/V |

설정 절차:
1. 센서에 **최대 하중**을 가한다
2. 보고되는 V/V 값이 선택한 게인의 범위 안에 충분히 들어오는지 확인
3. 범위를 벗어나면 한 단계 낮은 게인으로 변경

> ⚠️ 게인에 따른 오차: 1x와 8x 게인 사이에 약 **1.5% 차이**가 관찰된다. 최대 정확도를 위해 **캘리브레이션 전에 사용할 게인을 먼저 고정**하고 그 게인으로 시스템(보드+센서)을 통째로 보정할 것.
> 실리콘/압력 센서처럼 오프셋 편차가 큰 브리지는 낮은 게인만 사용해야 할 수 있다.

## 6. 데이터 레이트 설정

- **Data Interval**: 이벤트 사이 간격(ms). 반드시 **8ms의 배수**여야 하며, 라이브러리가 내림 처리한다 (예: 31 입력 → 24ms 적용).
- **Data Rate**: Data Interval의 역수 (Hz). 최대 122 samples/s.
- **Change Trigger**: 데이터 이벤트를 발생시키는 최소 변화량.
- 최소 간격 8ms 기준 실제 최대 샘플레이트는 약 122 Hz (8ms로 단순 계산한 125보다 약간 낮음).

## 7. 측정값 환산 및 캘리브레이션

### 7.1 측정 단위 (V/V)
- 1046은 절대 전압이 아닌 **공급 전압 대비 비율(ratiometric, V/V)**로 측정한다.
- V/V는 센서 출력 전압을 공급 전압 1V 기준으로 스케일한 값으로, 실제 공급 전압과 무관하게 센서가 측정하는 물리량에 비례한다.
- 대부분의 로드셀은 전체 하중에서 수 mV 수준의 출력을 내며, 정밀 센서는 mV/V 단위 **교정 성적서(certificate of calibration)**가 함께 제공된다.

### 7.2 캘리브레이션 절차 (선형 센서 기준)
로드셀은 응답이 선형이므로 2점 보정으로 무게/힘 환산식을 구할 수 있다.
1. 게인을 고정한다 (섹션 5 참고)
2. **무부하 상태**에서 V/V 값 측정 → 영점(offset) 기록
3. **기준 분동(known weight)**을 올리고 V/V 값 측정
4. 두 점으로 선형식 도출: `무게 = (측정 V/V − offset) × scale`
   - `scale = 기준무게 / (분동 적용 시 V/V − offset)`
5. 가능하면 여러 무게로 여러 점을 측정해 직선성 확인

> Windows용 **Load Cell Calibrator** C# 예제 코드가 제공된다. 자동 보정이 필요하면 활용할 것.
> 정밀 측정 시 시스템 전체(보드+센서+배선)를 하나의 단위로 보고 보정해야 한다.

## 9. 주의사항 요약

- 모든 센서 배선은 길이·굵기를 동일하게 (온도 오차 상쇄)
- 캘리브레이션 전 게인 고정 (게인 변경 시 ~1.5% 오차)
- 1046_0은 절대 전압 측정 불가 (비율 측정 전용)
- RTD 측정에는 이 제품 대신 **TMP1200(RTD Phidget)** 권장
- 센서 발열은 오차 요인 — 미사용 채널 전원 차단 활용
