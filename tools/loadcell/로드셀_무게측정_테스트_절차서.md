# 로드셀 무게 측정 테스트 절차서

> 구성: 컨베이어 하부 **로드셀 4개(코너 배치) → PhidgetBridge 1046(4채널 합산) → PC(USB)**
> 정량 목표: **0~60kg 범위에서 어떤 무게도 오차 ±0.5kg 이내** (= 60kg에서 0.83%)
> 검증 질문: ① 컨베이어 내부 로드셀로 정밀 무게 측정이 가능한가 ② 현재 선정한 로드셀(≤20kg)+회로 조합이 적합한가
> 측정 도구: **웹 대시보드(`loadcell_server.py` + 브라우저)** — 위치별 보정 + 제품별 테스트 항목 + 항목별 자동 기록
> 장비 사양·배선: `PhidgetBridge_1046_장비가이드.md` · 설치/실행: `README.md` 참고
> 작성일: 2026-06-23 · 업데이트: 2026-06-24 (웹 대시보드 구조 반영)

## ⚠️ 0. 가장 먼저 — 로드셀 용량 적정성 검토 (테스트 전 필수)

4코너 구성에서 한 셀이 받는 하중은 **물체 위치에 따라 크게 달라진다.** 현재 셀은 1개당 **≤20kg**이다.

| 적재 위치 | 한 셀 최대 분담 (60kg 기준) | 20kg 셀 대비 | 판정 |
|---|---|---|---|
| 정중앙 | 약 W/4 = **15kg** | 75% | △ 여유 부족(권장 ≤80%, 경계) |
| 한 변(2셀) 쏠림 | 약 W/2 = **30kg** | 150% | ✕ **과부하** |
| 한 코너(1셀) 집중 | 약 W ≈ **60kg** | 300% | ✕✕ **심각한 과부하·영구손상** |

**결론:** 4×20kg 구성은 **정중앙 60kg는 간신히 가능**하지만, 테스트 항목인 **"한쪽 쏠림 60kg"에서 개별 셀이 과부하**되어 셀이 손상되거나 비선형·영구 오프셋이 발생할 수 있다. 즉 현재 조합으로는 **편심(쏠림) 60kg 정량 목표를 안전하게 달성하기 어렵다.**

권장 조치 (택1):
1. **셀 용량 상향** — 쏠림 최악조건을 고려해 1개당 **≥50kg(C3급)** 권장. (셀 용량이 커져도 24-bit ADC와 C3 정밀도면 ±0.5kg 목표는 충분히 달성 가능)
2. **기계적 제약** — 컨베이어 프레임이 하중을 4셀로 강제 분산시켜 단일 셀 집중을 막는 구조라면 현 용량 유지 가능. → 이 경우 **쏠림 시 실제 단일 셀 부하를 먼저 측정·확인**할 것.
3. 현 용량 유지 시 **저용량(예: 5~30kg)부터 단계적으로** 진행하고, 쏠림 60kg는 셀 부하 실측으로 안전 확인 후에만 시도.

> 이 검토 결과를 검증 질문 ②의 1차 답으로 기록할 것. (안전·정밀도 양쪽에서 용량 재선정 권고)
> 대시보드는 어떤 채널이 **정격(`CH_MAX`, 기본 25kg)을 초과**하면 기록 시 **⚠ 경고**를 띄운다 — 셀 용량에 맞게 `CH_MAX`를 조정해 두면 과부하를 즉시 인지할 수 있다.

## 1. 준비물

- PhidgetBridge 1046 (4채널) 1개 + Mini-USB 케이블 + PC
- 로드셀 4개(코너) + 마운팅 브래킷/풋
- 기준 분동(known weight): **0.5kg급 + 1·5·10·25·30·60kg** (테스트용 물체를 그대로 기준값으로 사용 가능, 단 실제 질량을 정밀 저울로 사전 확인)
- 수평계, 멀티미터(셀 핀 확인용), 동일 규격 배선재(16~26 AWG)
- PC에 **Phidget22 라이브러리** + **측정 대시보드(`loadcell_server.py`)** (설치는 `README.md`)

## 2. 하드웨어 준비

### 2.1 기계적 설치 (정확도의 80%는 여기서 결정됨)
- 4개 셀을 코너에 대칭 배치하고 **상판(컨베이어)이 셀에만 하중을 전달**하도록 설치. 프레임·케이블·호스가 하중을 우회(bypass)하지 않게 한다.
- 컨베이어가 주변 구조물에 **닿거나 끼이지(binding) 않게** 띄울 것 — 마찰이 오차의 주원인.
- 셀 바닥면 **수평** 확보(수평계). 기울면 코너별 분담이 틀어진다.
- 모든 셀의 하중 방향(화살표)을 규정 방향으로 정렬.

### 2.2 배선
- 셀 4개를 1046의 **채널 0~3**에 각각 연결. 단자: `5V`/`G`(여기 전원), `+`/`−`(신호).
- 데이터시트 색상 규약대로 EXC+/EXC− → `5V`/`G`, SIG+/SIG− → `+`/`−`.
- 데이터시트 없으면: 4선 저항 6조합 측정 → 고저항 2조합 중 하나를 `5V`/`G`, 나머지를 `+`/`−`. 하중 시 값이 반대로 변하면 `+`/`−` 교체.
- **4채널 모두 배선 길이·굵기 동일하게** (온도 드리프트 상쇄).

> 배선·핀 판별·게인/데이터레이트 상세는 `PhidgetBridge_1046_장비가이드.md` 참고.

## 3. 측정 도구 — 웹 대시보드 (`loadcell_server.py` + 브라우저)

Python 백엔드가 USB 하드웨어를 읽고, 브라우저 UI로 측정·보정·기록한다.

### 3.1 핵심 개념 — 위치(모듈) · 유닛 · 제품
- **위치(모듈)** = 보정 단위 이름. 예: `mW2_1층` / `mW2_2층` / `w-station`. (`config.json` 의 `locations`)
- **유닛** = 위치 + 그 유닛에 꽂힌 **보드 시리얼**. 보정값은 그 물리적 셀+기구물+회로의 "지문"이라 **유닛마다 따로** 저장한다.
  → `<위치>_<시리얼>.json` = `{module, serial, zero[4], scale[4], updated}` (덮어쓰기 = 현재 보정 상태)
- **제품(테스트 대상)** = 무게×위치 테스트 항목 목록. 위치와 무관한 템플릿이며 GUI에서 직접 편집·생성한다.
  → `products/<제품>.json` = `{name, items[{nominal, position}]}`
- **저장 위치** = UI 하단 [변경]으로 지정하는 폴더(`config.json` 의 `output_dir`).

### 3.2 산출 파일 (저장 폴더에 생성)
| 파일 | 내용 |
|---|---|
| `<위치>_<시리얼>.json` | 그 유닛의 현재 보정값(zero/scale) — **덮어쓰기** |
| `<위치>_<시리얼>.csv` | 그 유닛의 측정 기록 — **append** |
| `calibration_history.csv` | 보정할 때마다 시각·단계·값 누적 (감사 이력) |

> 같은 위치라도 보드(시리얼)가 바뀌면 별도 파일로 남아 섞이지 않는다. 사전 등록 위치: `mW2_1층`, `mW2_2층`, `w-station`.

### 3.3 실행 / 접속
1. Phidget22 설치(`README.md`) 후 보드 USB 연결. **Phidget Control Panel은 반드시 닫는다**(점유 충돌 방지).
2. `start.command`(mac)·`start.bat`(win) 더블클릭, 또는 `python3 loadcell_server.py`.
3. 브라우저가 **http://localhost:8765** 를 자동으로 연다. (`index.html` 직접 열기(file://)는 동작 안 함)

### 3.4 화면 구성
- **선택 바** — 위치(드롭다운·[연결]·[＋새 위치]) / 제품(드롭다운·[새 제품]·[항목 편집])
- **총 무게** + **채널 막대 ch0~3**(채널별 무게·V/V, 정격 80% 초과 시 주황)
- **캘리브레이션 버튼** ① 영점 / ② 스팬 / ③ 코너(ch0~3) — 현재 연결된 유닛에 작용
- **테스트 항목 표** — 현재 제품의 항목별 [기록] 버튼
- **저장된 보정값 패널** — 파일명 + zero/scale 표시(보정·연결마다 갱신)
- **저장 폴더** — 경로 표시 + [변경]

### 3.5 주요 설정값 (`loadcell_server.py` 상단)
| 항목 | 기본값 | 의미 |
|---|---|---|
| `PORT` | 8765 | 웹 포트 |
| `GAIN` | 128x | 게인(보정 전 고정) |
| `DATA_INTERVAL` | 128ms | 데이터 간격(8ms 배수) |
| `CH_MAX` | 25.0 | 채널 정격 초과 경고 기준(kg) |
| `TOL_KG` | 0.5 | 합격 허용오차(§7) |

## 4. 캘리브레이션 (정량 목표 달성의 핵심) — 유닛별 ①②③

**위치를 [연결]한 상태에서**(보드 시리얼 자동 인식) ① → ② → ③ 순서로 1회 수행한다. 각 단계는 즉시 **그 유닛의 `<위치>_<시리얼>.json`** 에 저장되고(덮어쓰기), `calibration_history.csv` 에 이력으로 누적된다. 다음에 같은 유닛을 연결하면 자동으로 불러온다.

### 4.1 ① 영점(Zero/Tare) — 무부하
- **목적:** 무부하 상태를 0kg 기준으로 맞춰 셀·상판 자중을 상쇄.
- **방법:** 컨베이어 위를 완전히 비운 뒤 **[① 영점]**.
- ⚠️ 영점은 온도·시간·찌꺼기·기계적 안정화로 **드리프트**한다. 작업 시작(워밍업 후) 및 주기적으로 재영점.

### 4.2 ② 스팬(Span) — 기준 분동
- **목적:** 센서 신호(V/V)를 실제 kg으로 변환하는 공통 배율을 결정.
- **방법:** 기준 분동을 **정중앙**에 올리고 **[② 스팬]** → 분동 무게(kg) 입력.
- ⚠️ **"1kg로 스팬"은 권장하지 않음.** 1kg 기울기를 60kg로 외삽하면 오차가 60배 증폭. **운용 범위의 절반 이상(권장 ≥30kg)** 분동으로 잡을 것.

### 4.3 ③ 코너 보정(Corner Trimming) — 쏠림 정확도의 핵심
- **목적:** 편심(쏠림)에서도 같은 무게가 같게 나오도록 **채널별 배율**을 미세조정.
- **방법:** 동일 분동(예: 10~20kg)을 각 코너(ch0~3) 위에 차례로 올리고 해당 **[ch0]~[ch3]** 버튼. 정중앙·각 코너 합계가 ±0.5kg 내로 수렴할 때까지 반복.

> 유닛마다 보정이 따로다. 새 유닛/위치는 **연결 → ①②③를 다시** 잡는다.

## 5. 테스트 절차 (웹 대시보드)

**STEP 0 — 연결 & 보정**
1. 브라우저에서 **위치 선택 → [연결]** (보드 시리얼 자동 인식, 미감지 시 입력).
2. §4의 ①②③를 순서대로 완료. 무부하에서 총 무게 0kg ±0.1kg 확인.

**STEP 1 — 튜닝/캘리브레이션 검증**
- 보정 완료 상태에서 기준 분동을 올려 표시값이 기대값과 맞는지 확인 → "튜닝 가능" 판정.

**STEP 2 — 정중앙 적재 측정 (5→10→25→30→60kg)**
- 제품 선택(기본 제품에 10항목 내장). 각 무게를 **정중앙**에 올리고 안정화(2~3초) 후 **"…정중앙" 행 [기록]**.
- 재현성 확인 위해 같은 항목 3회 반복 기록.
- ⚠️ 60kg는 §0 용량 검토 통과 후에만.

**STEP 3 — 한쪽 쏠림 적재 측정 (5→10→25→30→60kg)**
- 각 무게를 **쏠리게** 적재 후 **"…쏠림" 행 [기록]**. 정중앙 값과의 **편차** ±0.5kg 내인지 확인.
- ⚠️ 쏠림은 단일 셀 과부하 위험 최대 → 저용량부터, 30kg↑는 셀 부하 실측 후. ⚠ 정격 초과 경고 시 즉시 중단.

> **[기록] 동작:** 약 0.4초 평균한 현재 무게를 그 항목으로 저장하고, 행에 **측정값·오차·PASS/FAIL**(±`TOL_KG`)을 색으로 표시하며 `<위치>_<시리얼>.csv` 에 누적한다.

## 7. 합격 판정 기준

- 모든 측정점에서 |실제−기대| ≤ **0.5kg** (대시보드가 PASS/FAIL로 표시)
- 동일 무게의 **정중앙 vs 쏠림 편차** ≤ 0.5kg (코너 보정 품질)
- 3회 반복 측정의 **재현성**(표준편차) 충분히 작음 — CSV로 편차 확인
- 측정 중 어떤 셀도 정격(20kg) 초과하지 않음(안전) — ⚠ 경고 미발생

| 1kg 소스팬 외삽 | 60kg에서 큰 오차 | 운용범위 절반↑ 기준·다점 보정 |

| 온도 드리프트 | 영점 변동 | 배선 동일화, 워밍업 후 측정, 주기적 재영점 |
| 게인 변경 | ~1.5% 오차 | 보정 전 게인 고정 |
| 보드 시리얼 미인식 | 연결 실패 | USB·Control Panel 종료 확인, 연결 시 시리얼 수동 입력 |
| 다른 유닛 보정 혼용 | 위치별 오차 급증 | 위치(유닛)마다 따로 연결·보정 (`<위치>_<시리얼>` 파일 분리) |
