# 로봇 테스트벤치 사용 설명서

> **이 문서는 누구를 위한 것인가요?**
> 로봇은 다루지만 프로그래밍·터미널은 다루지 않는 분(하드웨어팀·테스트 담당자 등)을 위한 **화면 사용 안내서**입니다.
> 설치·서버 켜는 방법은 다루지 않습니다(그건 [`README.md`](../README.md) 담당). 이 문서는 **이미 켜져 있는 툴을 브라우저로 열어 쓰는 법**만 설명합니다.

## 화면에 나오는 기호 읽는 법 (범례)

이 문서의 그림과 실제 화면에서 아래 기호가 똑같이 쓰입니다.

| 기호 | 뜻 |
|:--:|---|
| `●` (초록) | 연결됨 / 정상 |
| `○` (회색) | 끊김 / 꺼짐 / 비활성 |
| `▶` | 실행(시작) |
| `■` | 정지 |
| `+` | 추가 |
| `★` | **안전상 꼭 알아야 할 내용** |

> 이 설명서에는 사진이 없습니다. 대신 화면을 **글자 그림(─, │, ┌ 같은 선으로 그린 틀)** 으로 보여주고, **화면에 실제로 적힌 글자는 `이렇게` 따옴표로** 표시합니다. 자기 화면에서 똑같은 글자를 눈으로 찾으면 됩니다.

## 1. 시작하기

### 1.1 이 툴은 무엇을 하나요?

브라우저 하나로 로봇을 **관찰하고(센서·카메라·상태), 조종하고(수동 주행·목표 주행), 기록하는(데이터 녹화)** 도구입니다.
화면을 내가 원하는 대로 **패널(화면 조각)을 붙여 조립**해서 씁니다.

### 1.2 준비물

- 로봇 네트워크(Wi-Fi)에 접속된 PC 또는 노트북
- 웹 브라우저 (Chrome 권장)
- 접속 주소: **`http://192.168.34.202:8080`**

### 1.3 접속하기

브라우저 주소창에 위 주소를 입력하고 Enter → 아래와 같은 화면이 나타나면 성공입니다.

## 2. 화면 둘러보기

처음 접속하면 화면은 크게 **세 부분**으로 나뉩니다.

```
┌────────────────────────────────────────────────────────────┐
│ ● 연결됨   │ ● zenoh   ● 201 함께           CPU 23%  온도 47℃ │ ← ② 상태 막대
├──────────────┬─────────────────────────────────────────────┤
│ 대시보드      │                                             │
│ 워크스페이스   │                                             │
│ 관리자        │            [ 여기가 작업 영역 ]              │ ← ④ 작업 영역
│ ───────────  │         (고른 메뉴 화면이 여기 표시)          │
│  💾 스냅샷1   │                                             │
│  💾 스냅샷2   │                                             │ ← ③ 왼쪽 메뉴(사이드바)
└──────────────┴─────────────────────────────────────────────┘
```

~~**① 비상 정지 막대** — 화면 맨 위 빨간 막대. `비상 정지 (E-STOP)` 버튼이 **어느 화면에서나 항상** 있습니다. ★~~

**② 상태 막대** — 지금 연결 상태를 한 줄로 보여줍니다.

| 표시 | 의미 |
|---|---|
| `● 연결됨` / `○ 연결 끊김` | 툴과 브라우저의 연결 상태 |
| `● zenoh` | 로봇 통신망(zenoh) 연결 — 초록이어야 데이터가 들어옵니다 |
| `● 201 함께` / `○ 201 단독` | 컨트롤러(모터 담당 PC, 201)가 같이 켜져 있는지 |
| `● 201 SSH✗` (빨강) | 201은 보이지만 원격 명령이 막힌 상태 → **담당자에게 문의** |
| `CPU 23%` / `온도 47℃` | 서버 PC의 현재 부하·온도 |

**③ 왼쪽 메뉴(사이드바)** — 큰 화면 세 개를 오갑니다. 그 아래에는 **저장해 둔 화면 구성(스냅샷)** 목록이 붙습니다.

| 메뉴 | 무엇을 하나 |
|---|---|
| `대시보드` | 로봇 전체 상태를 한눈에 보는 요약 화면 |
| `워크스페이스` | 내가 패널을 조립해 관찰·조종·녹화하는 **주 작업 화면** |
| `관리자` | 로봇 기동 순서(시작 플랜)를 편집·실행 — **주의 필요** |

**④ 작업 영역** — 왼쪽 메뉴에서 고른 화면이 나오는 넓은 공간.

## 3. 꼭 알아야 할 개념 3가지

### 개념 1. "보이는 것"과 "내가 켠 것"은 다릅니다 ★

툴을 열면 화면에 로봇 데이터가 채워집니다. **하지만 이건 툴이 로봇을 켠 것이 아니라, 이미 켜져 있던 로봇을 "들여다보는" 것**입니다.
로봇·기능을 **실제로 켜고 끄는** 것은 `워크스페이스`의 **`런치` 패널**과 `관리자`의 **시작 플랜**뿐입니다. 보는 것만으로는 로봇이 움직이지 않습니다.

### 개념 2. 패널 = 화면 조각, 워크스페이스 = 내가 조립한 화면

`워크스페이스`는 처음엔 빈 화면입니다. 여기에 **패널을 하나씩 추가**해 내가 원하는 화면을 만듭니다.
(예: 왼쪽엔 카메라, 오른쪽엔 온도 그래프, 아래엔 조종 패드)

### 개념 3. 스냅샷 = 내가 만든 화면 구성의 저장본

힘들게 조립한 화면을 **이름 붙여 저장**해두면, 다음에 왼쪽 메뉴에서 한 번 클릭으로 똑같이 불러올 수 있습니다.

## 4. 작업별 따라하기

> 아래는 모두 `워크스페이스` 화면에서 합니다. 왼쪽 메뉴에서 `워크스페이스`를 먼저 클릭하세요.

### 4.0 패널 추가하기 (모든 작업의 시작)

빈 워크스페이스는 이렇게 보입니다.

```
┌──────────────────────────────────────────────┐
│  워크스페이스                  [+ 패널 추가]   │
│                                              │
│              ┌───────────┐                    │
│              │     +     │                    │
│              └───────────┘                    │
│      패널을 추가해 워크스페이스를 구성하세요    │
│                                              │
│  [플롯] [메시지] [네비게이션] [카메라] [녹화]   │
│  [텔레옵] [명령] [런치] [컨트롤러] [Diagnostics]│
└──────────────────────────────────────────────┘
```

1. 가운데의 패널 종류 버튼을 클릭하거나, 오른쪽 위 **`패널 추가`** 버튼을 누릅니다.
   → 고른 패널이 작업 영역에 나타납니다.
2. 패널은 **제목을 끌어(드래그)** 위치를 바꿀 수 있습니다.
3. 오른쪽 위 **`1열` / `2열` / `3열`** 로 화면을 몇 칸으로 나눌지 정합니다.

**어떤 패널을 골라야 하나요?**

```
무엇을 하고 싶나요?
 ├ 센서 값을 그래프/표로 보기      → 「플롯」
 ├ 토픽 원본 메시지 그대로 보기     → 「메시지」
 ├ 카메라 영상 보기               → 「카메라」
 ├ 지도 위 로봇 위치·목표 주행      → 「네비게이션」
 ├ 로봇을 직접 손으로 조종         → 「텔레옵」
 ├ 데이터를 파일(CSV)로 받기       → 「녹화」
 ├ 명령 한 번 보내기(고급)         → 「명령」
 ├ 로봇 기능을 켜고 끄기           → 「런치」
 ├ 모터 제어기 켜고 끄기           → 「컨트롤러」 // 아직 만들어지는중
 └ 로봇 자가진단(온도·전류 등) 보기 → 「Diagnostics」 // 대부분 토픽 플롯으로 볼 수 있음
```

---

### 4.1 센서 값을 그래프로 보기 — 「플롯」 패널

1. `패널 추가` → **`플롯`** 을 고릅니다.
2. 패널 안에서 **`토픽 소스`** 또는 **`시스템 소스`** 중 무엇을 볼지 고릅니다.
   - **토픽** = 로봇이 내보내는 데이터(예: 바퀴 속도)
   - **시스템** = 서버 PC 상태(CPU·메모리·온도·네트워크 등)
3. 보고 싶은 항목을 드롭다운에서 고릅니다.
   → 선이 실시간으로 그려지기 시작하면 정상입니다.
4. **`표` / `그래프`** 토글로 숫자표와 꺾은선그래프를 전환할 수 있습니다.

> 그래프가 안 그려지면: 상태 막대의 `zenoh`가 초록(`●`)인지 확인하세요. 회색이면 데이터가 안 들어오는 상태입니다.

---

### 4.2 카메라 영상 보기 — 「카메라」 패널

1. `패널 추가` → **`카메라`** 를 고릅니다.
2. 카메라 토픽(RGB 또는 Depth)을 고릅니다.
   → 영상이 실시간으로 나오면 정상입니다.

---

### 4.3 로봇을 직접 조종하기 — 「텔레옵」 패널 ★

로봇이 실제로 **움직이는** 기능입니다. 주변에 사람·장애물이 없는지 먼저 확인하세요. ★

1. `패널 추가` → **`텔레옵`** 을 고릅니다.

**방법 A. 화면에서 마우스로**
- 화면의 **XY 패드를 끌면** 전후·좌우 이동, **회전 슬라이더**로 회전합니다.
- 손을 떼면 멈춥니다.

**방법 B. 키보드로**
- 패널의 **`여기를 클릭해 키 입력 활성화`** 영역을 한 번 클릭합니다. (클릭해야 키가 먹습니다)
- 방향키로 이동합니다. **키에서 손을 떼면 즉시 정지**합니다. ★

**방법 C. 게임패드로 (USB 연결)**
- 게임패드를 USB로 연결하면 패널 아래에 스틱·버튼 모양이 실시간으로 움직입니다(인식 확인).

| 조작 | 동작 |
|---|---|
| **LT (왼쪽 뒤 버튼)** | **데드맨 — 누르고 있는 동안만 명령 전달. 떼면 즉시 정지** ★ |
| 왼쪽 스틱 | 전후·좌우 이동 |
| 오른쪽 스틱 | 제자리 회전 |
| RB + 왼쪽 스틱 | 횡이동(게걸음) |

> 세 방법 모두 **손을 떼면 멈추도록** 설계되어 있습니다. 그래도 위급하면 맨 위 `비상 정지 (E-STOP)`. ★

---

### 4.4 목표 지점으로 주행 — 「네비게이션」 패널 ★

지도 위에서 로봇을 목표 지점으로 보냅니다. 로봇이 **스스로 움직입니다**. ★

1. `패널 추가` → **`네비게이션`** 을 고릅니다.
   → 지도(map)·장애물(scan)·로봇 위치가 표시됩니다. 마우스로 화면을 끌어 이동(pan), 휠로 확대(zoom).
2. **`2D Pose Estimate`** — 로봇이 자기 위치를 잘못 알 때, 실제 위치를 찍어 알려줍니다.
3. **`Nav Goal`** — 목표 지점을 클릭하면 로봇이 그곳으로 주행합니다.
4. **`주행 취소`** — 진행 중인 주행을 멈춥니다.

---

### 4.5 데이터를 파일로 받기 — 「녹화」 패널

테스트 데이터를 표(CSV) 파일로 저장합니다.

1. `패널 추가` → **`녹화`** 를 고릅니다.
2. 녹화할 대상(토픽 / diagnostics / 시스템 값)을 고릅니다.
3. **`▶` 시작**을 누르면 `녹화 중` 표시가 뜹니다.
4. **`■` 정지** 후 **CSV 다운로드**로 파일을 받습니다. (한 줄에 여러 값이 함께 들어가는 Wide CSV)

---

### 4.6 로봇 기능 켜고 끄기 — 「런치」 패널 ★

이 패널은 **로봇/노드를 실제로 켜고 끕니다**(모터 런치 포함 시 로봇이 움직일 수 있음). ★

1. `패널 추가` → **`런치`** 를 고릅니다.
   → 서버(202)·컨트롤러(201)에 설치된 실행 가능한 런치 목록이 나옵니다.
2. 원하는 항목의 **`▶ 실행`** / **`■ 종료`** 를 누릅니다.
   → 모터·주행이 동반되는 항목은 **확인 창**이 한 번 더 뜹니다. ★
3. 워크스페이스 맨 위 **`실행 중 런치`** 줄의 **`파악`** 버튼을 누르면 지금 무엇이 돌고 있는지 확인됩니다.

---

### 4.7 모터 제어기 켜고 끄기 — 「컨트롤러」 패널

1. `패널 추가` → **`컨트롤러`** 를 고릅니다.
   → 제어기 목록과 활성/비활성 상태가 나옵니다.
2. 각 제어기를 활성/비활성으로 전환합니다.

---

### 4.8 내 화면 구성 저장·불러오기 — 스냅샷

워크스페이스 오른쪽 위 영역에서 합니다.

```
[교체|추가]  [스냅샷 불러오기… ▼]  [💾 저장]  [🗑 ▼]
```

**저장하기**
1. **`저장`** 버튼을 누릅니다.
2. 이름을 입력합니다(예: `모터 온도 테스트`) → **`저장`**.
   → 왼쪽 메뉴 `워크스페이스` 아래에 그 이름이 나타납니다.
3. 이미 불러온 스냅샷을 수정했다면 버튼이 **`저장(덮어쓰기)`** 로 바뀝니다. 같은 이름이면 덮어쓰고, 이름을 바꾸면 새로 저장됩니다.

**불러오기**
- **빠른 방법**: 왼쪽 메뉴에서 저장된 이름을 클릭.
- **드롭다운**: `스냅샷 불러오기…` 에서 선택.
  - **`교체`** = 지금 화면을 그 구성으로 바꿈
  - **`추가`** = 지금 화면에 그 구성을 합쳐서 함께 표시

**삭제하기** — 휴지통(`🗑`) 드롭다운에서 이름을 고르면 확인 후 삭제됩니다.

## 5. 안전 수칙 ★

| 상황 | 해야 할 것 |
|---|---|
| **위급 — 로봇을 당장 멈춰야 함** | 화면 맨 위 빨간 **`비상 정지 (E-STOP)`** 클릭. 모든 이동 명령 0 + 활성 제어기 비활성 + 주행 취소 |
| 텔레옵으로 조종 중 | 손/키/데드맨(LT)을 **떼면 즉시 정지**. 떼는 게 곧 정지 |
| `런치`로 기능 켤 때 | 모터·주행 포함 항목은 **확인 창**을 반드시 읽고 누르기 |
| 주변에 사람·장애물 | 텔레옵·네비게이션·모터 런치 **시작 전 반드시 확인** |

> **`비상 정지`는 어느 화면에서나 맨 위에 항상 있습니다.** 망설이지 말고 누르세요. ★

## 6. 문제 해결 (자주 묻는 질문)

| 증상 | 원인 | 조치 |
|---|---|---|
| 화면이 안 뜨거나 "연결 끊김" | Wi-Fi 미접속 / 주소 오타 / 서버 꺼짐 | 로봇 Wi-Fi 연결 확인 → 주소 `http://192.168.34.202:8080` 재확인 |
| 그래프·카메라에 데이터가 안 나옴 | 상태 막대 `zenoh`가 회색(`○`) | 로봇 통신망 미연결 — 담당자 문의 |
| `201 단독` 또는 `201 SSH✗` 표시 | 컨트롤러(모터 PC) 미연결/원격 막힘 | 모터 관련 기능 제한됨 — 담당자 문의 |
| `런치` 종료 버튼이 안 먹음 | 201 원격 명령 불가(`201 SSH✗`) | 담당자에게 SSH 설정 요청 |
| "플랜 로드 실패" 등 모든 기능 오류 | 접속 주소 문제 | 위 30초 요약의 주소로 다시 접속 |
| 텔레옵에서 키가 안 먹음 | 키 입력 영역 미활성 | 패널의 **`여기를 클릭해 키 입력 활성화`** 를 클릭 |
