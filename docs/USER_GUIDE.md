# 로봇 테스트벤치 사용 설명서

> **이 문서는 누구를 위한 것인가요?**
> 로봇은 다루지만 프로그래밍·터미널은 다루지 않는 분(하드웨어팀·테스트 담당자 등)을 위한 **화면 사용 안내서**입니다.
> 설치·서버 켜는 방법은 다루지 않습니다(그건 [`README.md`](../README.md) 담당). 이 문서는 **이미 켜져 있는 툴을 브라우저로 열어 쓰는 법**만 설명합니다.

## 0. 30초 요약 (급할 때 이것만)

1. 로봇 Wi-Fi에 연결된 PC에서 브라우저를 엽니다.
2. 주소창에 **`http://192.168.34.202:8080`** 을 입력합니다.
3. 화면이 뜨면 끝 — 왼쪽 메뉴에서 **`대시보드`**(상태 보기) / **`워크스페이스`**(직접 조립) 로 이동합니다.
4. 조종 중 멈추려면 **조종 입력에서 손을 떼고**(텔레옵은 떼면 즉시 정지), 주행 중이면 네비게이션의 **`주행취소`** 를 누르세요. ★

## 화면에 나오는 기호 읽는 법 (범례)

이 문서의 그림과 실제 화면에서 아래 기호가 똑같이 쓰입니다.

| 기호 | 뜻 |
|:--:|---|
| `●` (초록) | 연결됨 / 정상 |
| `○` (회색) | 끊김 / 꺼짐 / 비활성 |
| `▶` | 실행(시작) |
| `■` | 정지 |
| `+` | 추가 |
| `★` | **안전상 꼭 알아야 할 내용** |

> 이 설명서에는 사진이 없습니다. 대신 화면을 **글자 그림(─, │, ┌ 같은 선으로 그린 틀)** 으로 보여주고, **화면에 실제로 적힌 글자는 `이렇게` 따옴표로** 표시합니다. 자기 화면에서 똑같은 글자를 눈으로 찾으면 됩니다.

## 1. 시작하기

### 1.1 이 툴은 무엇을 하나요?

브라우저 하나로 로봇을 **관찰하고(센서·카메라·상태), 조종하고(수동 주행·목표 주행), 기록하는(데이터 녹화)** 도구입니다.
화면을 내가 원하는 대로 **패널(화면 조각)을 붙여 조립**해서 씁니다.

### 1.2 준비물

- 로봇 네트워크(Wi-Fi)에 접속된 PC 또는 노트북
- 웹 브라우저 (Chrome 권장)
- 접속 주소: **`http://192.168.34.202:8080`**

### 1.3 접속하기

브라우저 주소창에 위 주소를 입력하고 Enter → 아래와 같은 화면이 나타나면 성공입니다.

---

## 2. 화면 둘러보기

처음 접속하면 화면은 크게 **세 부분**으로 나뉩니다.

```
┌────────────────────────────────────────────────────────────┐
│ ● 연결됨   │ ● zenoh   ● 201 함께           CPU 23%  온도 47℃ │ ← ① 상태 막대
├──────────────┬─────────────────────────────────────────────┤
│ 대시보드      │                                             │
│ 워크스페이스   │                                             │
│ 관리자        │            [ 여기가 작업 영역 ]              │ ← ③ 작업 영역
│ ───────────  │         (고른 메뉴 화면이 여기 표시)          │
│  💾 스냅샷1   │                                             │
│  💾 스냅샷2   │                                             │ ← ② 왼쪽 메뉴(사이드바)
└──────────────┴─────────────────────────────────────────────┘
```

**① 상태 막대** — 지금 연결 상태를 한 줄로 보여줍니다.

| 표시 | 의미 |
|---|---|
| `● 연결됨` / `○ 연결 끊김` | 툴과 브라우저의 연결 상태 |
| `● zenoh` | 로봇 통신망(zenoh) 연결 — 초록이어야 데이터가 들어옵니다 |
| `● 201 함께` / `○ 201 단독` | 컨트롤러(모터 담당 PC, 201)가 같이 켜져 있는지 |
| `● 201 SSH✗` (빨강) | 201은 보이지만 원격 명령이 막힌 상태 → **담당자에게 문의** |
| `CPU 23%` / `온도 47℃` | 서버 PC의 현재 부하·온도 |

**② 왼쪽 메뉴(사이드바)** — 큰 화면 세 개를 오갑니다. 그 아래에는 **저장해 둔 화면 구성(스냅샷)** 목록이 붙습니다.

| 메뉴 | 무엇을 하나 | 자세히 |
|---|---|---|
| `대시보드` | 로봇 전체 상태를 한눈에 보는 요약 화면 | [→](guide/dashboard.md) |
| `워크스페이스` | 내가 패널을 조립해 관찰·조종·녹화하는 **주 작업 화면** | [→](guide/workspace-basics.md) |
| `관리자` | 로봇 기동 순서(시작 플랜)를 편집·실행 — **주의 필요** | [→](guide/admin-startup.md) |

**③ 작업 영역** — 왼쪽 메뉴에서 고른 화면이 나오는 넓은 공간.

## 3. 꼭 알아야 할 개념 3가지

### 개념 1. "보이는 것"과 "내가 켠 것"은 다릅니다 ★

툴을 열면 화면에 로봇 데이터가 채워집니다. **하지만 이건 툴이 로봇을 켠 것이 아니라, 이미 켜져 있던 로봇을 "들여다보는" 것**입니다.
로봇·기능을 **실제로 켜고 끄는** 것은 `워크스페이스`의 **[`런치` 패널](guide/panel-launch.md)** 과 `관리자`의 **[시작 플랜](guide/admin-startup.md)** 뿐입니다. 보는 것만으로는 로봇이 움직이지 않습니다.

### 개념 2. 패널 = 화면 조각, 워크스페이스 = 내가 조립한 화면

`워크스페이스`는 처음엔 빈 화면입니다. 여기에 **패널을 하나씩 추가**해 내가 원하는 화면을 만듭니다.
(예: 왼쪽엔 카메라, 오른쪽엔 온도 그래프, 아래엔 조종 패드) → [워크스페이스 기본](guide/workspace-basics.md)

### 개념 3. 스냅샷 = 내가 만든 화면 구성의 저장본

힘들게 조립한 화면을 **이름 붙여 저장**해두면, 다음에 왼쪽 메뉴에서 한 번 클릭으로 똑같이 불러올 수 있습니다. → [스냅샷](guide/snapshots.md)

## 4. 작업별 빠른 안내

> 모두 `워크스페이스` 화면에서 합니다. 각 항목의 **[자세히]** 링크에 단계·옵션·문제해결이 정리돼 있습니다.

**어떤 패널을 골라야 하나요?**

```
무엇을 하고 싶나요?
 ├ 센서 값을 그래프/표로 보기      → 「플롯」
 ├ 토픽 원본 메시지 그대로 보기     → 「메시지」
 ├ 카메라 영상 보기               → 「카메라」
 ├ 지도 위 로봇 위치·목표 주행      → 「네비게이션」
 ├ 로봇을 직접 손으로 조종         → 「텔레옵」
 ├ 데이터를 파일(CSV)로 받기       → 「녹화」
 ├ 명령 한 번 보내기(고급)         → 「명령」
 ├ 로봇 기능을 켜고 끄기           → 「런치」
 ├ 모터 제어기 켜고 끄기           → 「컨트롤러」(기능 정비 중일 수 있음)
 └ 로봇 자가진단(온도·전류 등) 보기 → 「Diagnostics」(상당수는 플롯으로도 볼 수 있음)
```

| 하고 싶은 일 | 패널 | 자세히 |
|---|---|---|
| 센서·시스템 값을 그래프/표로 | 플롯 | [자세히](guide/panel-plot.md) |
| 토픽 원본 메시지 그대로 | 메시지 | [자세히](guide/panel-message.md) |
| 카메라 영상 | 카메라 | [자세히](guide/panel-camera.md) |
| 지도 위 목표 주행 ★ | 네비게이션 | [자세히](guide/panel-nav.md) |
| 로봇 직접 조종 ★ | 텔레옵 | [자세히](guide/panel-teleop.md) |
| 데이터 CSV 기록 | 녹화 | [자세히](guide/panel-recorder.md) |
| 명령 직접 보내기(고급) ★ | 명령 | [자세히](guide/panel-command.md) |
| 로봇 기능 켜고 끄기 ★ | 런치 | [자세히](guide/panel-launch.md) |
| 모터 제어기 전환 ★ | 컨트롤러 | [자세히](guide/panel-controllers.md) |
| 자가진단 보기 | Diagnostics | [자세히](guide/panel-diagnostics.md) |

> ★ 표시 패널은 **로봇이 움직이거나 상태가 바뀔 수 있습니다.** 아래 §5 안전 수칙을 먼저 읽으세요.

## 5. 안전 수칙 ★

| 상황 | 해야 할 것 |
|---|---|
| **조종 중 멈추고 싶음** | **조종 입력에서 손을 뗀다.** 텔레옵은 화면패드·게임패드(LT)·키보드 모두 **떼면 즉시 정지** |
| 자율 주행 중 멈추고 싶음 | 네비게이션 패널의 **`주행취소`** |
| 모터가 계속 움직임 | [컨트롤러 패널](guide/panel-controllers.md)에서 해당 제어기 **`비활성`**, 또는 [런치 패널](guide/panel-launch.md)에서 **`종료`** |
| `런치`·`관리자`로 기능 켤 때 | 모터·주행 포함 항목은 **확인 창**을 반드시 읽고 누르기 |
| 주변에 사람·장애물 | 텔레옵·네비게이션·모터 런치 **시작 전 반드시 안전 공간 확인** |

> 텔레옵은 **누르고 있는 동안만** 명령이 나가는 "데드맨" 방식입니다 — 위급하면 **손만 떼면** 멈춥니다. 물리적 위급 상황은 **현장 안전 수칙(로봇 하드웨어 정지 수단)** 을 따르세요.

## 6. 문제 해결 (자주 묻는 질문)

| 증상 | 원인 | 조치 |
|---|---|---|
| 화면이 안 뜨거나 "연결 끊김" | Wi-Fi 미접속 / 주소 오타 / 서버 꺼짐 | 로봇 Wi-Fi 연결 확인 → 주소 `http://192.168.34.202:8080` 재확인 |
| 그래프·카메라에 데이터가 안 나옴 | 상태 막대 `zenoh`가 회색(`○`) | 로봇 통신망 미연결 — 담당자 문의 |
| `201 단독` 또는 `201 SSH✗` 표시 | 컨트롤러(모터 PC) 미연결/원격 막힘 | 모터 관련 기능 제한됨 — 담당자 문의 |
| `런치` 종료 버튼이 안 먹음 | 201 원격 명령 불가(`201 SSH✗`) | 담당자에게 SSH 설정 요청 |
| "플랜 로드 실패" 등 모든 기능 오류 | 접속 주소 문제 | 위 30초 요약의 주소로 다시 접속 |
| 텔레옵에서 키가 안 먹음 | 키 입력 영역 미활성 | 패널의 **`여기를 클릭해 키 입력 활성화`** 를 클릭 |
| 패널에 "… 기동 필요" 안내 | 관련 노드가 안 켜짐 | [런치 패널](guide/panel-launch.md)로 해당 기능을 먼저 켜기 |
