# 워크스페이스 기본 — 패널 조립·배치

> [← 사용 설명서 목차](../USER_GUIDE.md) · 관련: [스냅샷](snapshots.md)

`워크스페이스`는 **빈 화면에서 시작**해 원하는 **패널을 붙여 조립**하는 주 작업 화면입니다.

---

## 패널 추가하기

빈 화면에는 안내가 보입니다: `패널을 추가해 워크스페이스를 구성하세요`.

- 가운데 패널 버튼을 직접 누르거나, 오른쪽 위 **`패널 추가`** 버튼을 누릅니다.
- 패널은 10종입니다.

| 패널 | 용도 | 세부 문서 |
|---|---|---|
| 플롯 | 값 그래프/표 | [panel-plot](panel-plot.md) |
| 메시지 | 원본 메시지 보기 | [panel-message](panel-message.md) |
| 네비게이션 | 지도·목표 주행 | [panel-nav](panel-nav.md) |
| 카메라 | 영상 보기 | [panel-camera](panel-camera.md) |
| 녹화 | CSV 기록 | [panel-recorder](panel-recorder.md) |
| 텔레옵 | 수동 조종 | [panel-teleop](panel-teleop.md) |
| 명령 | 발행/호출(고급) | [panel-command](panel-command.md) |
| 런치 | 기능 켜고 끄기 | [panel-launch](panel-launch.md) |
| 컨트롤러 | 제어기 전환 | [panel-controllers](panel-controllers.md) |
| Diagnostics | 자가진단 | [panel-diagnostics](panel-diagnostics.md) |

## 배치·정리

| 하고 싶은 것 | 방법 |
|---|---|
| 패널 위치 바꾸기 | 패널 **제목(헤더)을 끌어** 다른 자리로 드래그 |
| 화면 칸 수 | 오른쪽 위 `1열` / `2열` / `3열` 선택 |
| 패널 더 넣기 | 그리드 끝의 희미한 `+ 패널 추가` 자리를 클릭 |
| 표시 토픽 줄이기 | `플롯 가능만` 체크 — 그래프 가능한 토픽만 목록에 |

## 패널 공통 기능 (모든 패널 헤더)

| 기능 | 방법 |
|---|---|
| 제목 바꾸기 | 패널 **제목을 더블클릭** → 입력 후 Enter(취소는 Esc) |
| 접기/펼치기 | 헤더의 ▼/▶ 아이콘 |
| 최대화/복원 | 헤더의 최대화 아이콘 (전체 화면처럼 키우기) |
| 삭제 | 헤더의 X 버튼 |

## 실행 중 런치 확인

워크스페이스 맨 위에 **`실행 중 런치`** 줄이 있습니다.

- **`파악`** 버튼을 누르면 지금 서버(202)·컨트롤러(201)에서 돌고 있는 런치를 스캔해 보여줍니다(`확인 중…` → 결과).
- 아무것도 없으면 `실행 중 ros2 launch 없음`, 아직 안 눌렀으면 `'파악'을 눌러 확인`.
