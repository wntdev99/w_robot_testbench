# 관리자 — 시작 플랜 (주의: 파괴적 동작)

> [← 사용 설명서 목차](../USER_GUIDE.md)

로봇을 **정해진 순서대로 기동**하는 "시작 플랜"을 편집·실행하는 화면입니다(왼쪽 메뉴 `관리자`).

> 🛑 **이 화면의 `적용`은 파괴적입니다.** 서버(202)〔필요 시 컨트롤러(201) 포함〕의 **모든 ros2 프로세스를 종료**한 뒤, 통신망(zenoh)을 확인·기동하고, 정해진 단계를 순서대로 다시 켭니다. **모터 런치가 포함되면 로봇이 움직일 수 있습니다.**
> 의미를 정확히 아는 담당자만, **로봇 주변 안전 공간을 확보한 상태**에서 사용하세요.

---

## 무엇을 하는 화면인가

- 로봇을 켤 때 **무엇을, 어느 머신에서, 어떤 순서·간격으로** 기동할지 목록(단계)으로 정의합니다.
- 부팅 시 자동 실행 여부도 여기서 정합니다(자동이라도 **팝업 승인 후** 실행).

## 옵션

| 옵션 | 의미 |
|---|---|
| `서버 기동 시 자동 실행 (auto_on_boot)` | 서버가 켜질 때 이 플랜을 (승인 팝업과 함께) 실행할지 |
| `시작 전 기존 ros2 종료 (clean slate)` | 기동 전에 기존 프로세스를 모두 정리할지 |
| 종료 대상 `서버(202)` / `컨트롤러(201)` | 정리(종료) 대상 머신 선택 |

## 실행 단계 편집

`실행 단계 (순서 · 간격)` 영역에서 단계를 구성합니다.

- **`+ 단계 추가`** 로 단계를 더합니다.
- 각 단계: **라벨 · 머신(`서버`/`201`) · 종류(`launch`/`node`/`zenoh`) · 대기 시간(초) · 명령** + 순서 이동(↑↓)·삭제(🗑).

## 버튼 3개

| 버튼 | 동작 |
|---|---|
| `저장` | 플랜만 저장(실행 안 함) |
| `기존 ros2 종료만` (빨강) | 선택한 머신의 ros2 프로세스를 모두 종료만 함 |
| `저장 후 적용(종료→기동)` (빨강) | 저장 → **종료 → 순서대로 기동** 까지 실행 |

각 위험 버튼은 누르면 **확인 창**이 뜹니다.
- 적용: `기존 모든 ros2 프로세스를 종료하고 시작 플랜을 실행합니다. … 안전 공간 확인. 계속할까요?`
- 종료만: `… 의 ros2 프로세스를 모두 종료합니다. 계속?`

## 실행 중에 보이는 것

- **시작 팝업** — 부팅 후 승인이 필요할 때 `서버 시작 플랜 실행` 팝업이 뜹니다. `종료 후 기동(적용)` 또는 `건너뛰기`.
- **진행 오버레이** — 실행 중 `시작 플랜 진행 중`(단계별 진행·퍼센트)이 표시되고, 끝나면 `완료`/`실패`로 바뀝니다.
- 아래 `현재 관리 중 프로세스` 에서 기동된 프로세스를 확인합니다.

## 알아두기

- 평소 일부 기능만 켜고 끌 때는 이 화면이 아니라 [런치 패널](panel-launch.md)을 쓰세요(파괴적이지 않음).
- "관측 ≠ 제어": 단순히 화면을 보는 것만으로는 로봇이 기동되지 않습니다. 실제 기동은 이 시작 플랜과 런치 패널을 통해서만 일어납니다.
