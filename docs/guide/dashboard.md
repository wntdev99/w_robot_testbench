# 대시보드 — 로봇 상태 한눈에 보기

> [← 사용 설명서 목차](../USER_GUIDE.md)

접속하면 처음 보이는 **요약 화면**입니다(왼쪽 메뉴 `대시보드`). 로봇·서버 상태를 카드로 한눈에 보고, 바로 작업을 시작합니다.

---

## 화면 구성

```
┌──────────────────────────────────────────────────────────┐
│  안녕하세요 👋  로봇 상태를 한눈에…       [워크스페이스 열기]│
├──────────────────────────────────────────────────────────┤
│ ┌zenoh┐ ┌컨트롤러201┐ ┌인터넷┐ ┌비상정지┐  ← 전체 상태 4카드 │
│ ┌─ 서버(202) ─────┐  ┌─ 컨트롤러(201) ─┐                   │
│ │ CPU·메모리·온도  │  │ 연결·지연        │                   │
│ └──────────────────┘  └──────────────────┘                 │
│ [실행 중 프로세스]  [저장된 스냅샷]  [프로파일]  [최근 녹화] │
└──────────────────────────────────────────────────────────┘
```

## 카드별 내용

| 카드 | 보여주는 것 |
|---|---|
| **전체 상태 4카드** | `zenoh`(ON/OFF) · `컨트롤러 201`(함께/단독) · `인터넷`(정상/끊김) · `비상정지`(발동됨/정상) |
| **서버(202)** | CPU·메모리(%), 최고온도(℃, 70↑ 빨강·55↑ 주황), 네트워크 ↓↑(KB/s) |
| **컨트롤러(201)** | 연결 상태(함께/단독), 지연(ms) |
| **실행 중 프로세스** | testbench가 켜서 관리 중인 프로세스(상태·머신·pid). 없으면 `testbench가 기동·관리 중인 프로세스 없음` |
| **저장된 테스트 구성 (스냅샷)** | 저장한 화면 구성 목록. 클릭하면 `이 구성으로 열기 →` 로 워크스페이스 진입 |
| **프로파일 (런치 묶음)** | 런치 묶음. 선택 프로파일은 `▶ 기동` / `■ 종료` |
| **최근 녹화** | 최근 CSV 파일(있을 때만, 최대 5개) — 다운로드 링크 |

## 바로 가기

- 오른쪽 위 **`워크스페이스 열기`** → 패널을 조립하는 주 작업 화면으로.
- **스냅샷 카드 클릭** → 저장해 둔 구성을 그대로 불러오며 워크스페이스로.

## 알아두기

- 카드 상태가 대부분 회색/끊김이면, 로봇이 안 켜졌거나 통신망(zenoh)이 끊긴 것입니다 → 담당자 문의.
- 상태 막대(맨 위 줄) 읽는 법은 [목차 문서 §2](../USER_GUIDE.md)를 참고하세요.
