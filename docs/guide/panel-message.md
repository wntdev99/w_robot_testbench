# 「메시지」 패널 — 토픽 원본 메시지 그대로 보기

> [← 사용 설명서 목차](../USER_GUIDE.md) · 관련: [토픽 안내](../topic-map.md)

선택한 토픽의 **가장 최근 메시지 1건**을 항목(이름)–값 표로 그대로 펼쳐 보여줍니다. 그래프로 만들기 어려운 데이터(문자·구조가 복잡한 메시지)를 눈으로 확인할 때 씁니다. (터미널의 `topic echo`를 화면으로 옮긴 것)

---

## 사용법 (단계)

1. `패널 추가` → **`메시지`**.
2. 위쪽 **`토픽…`** 드롭다운에서 토픽을 고릅니다.
   → 그 토픽의 최신 메시지가 **항목 → 값** 표로 펼쳐집니다.
3. 값이 너무 빨리 바뀌어 읽기 어려우면 **`⏸ 일시정지`** 를 누릅니다.
   → 그 순간 메시지가 화면에 고정됩니다. 다시 **`▶ 재개`** 로 풀립니다.

## 화면 요소

| 요소 | 라벨 | 동작 |
|---|---|---|
| 토픽 드롭다운 | `토픽…` | 볼 토픽 선택. 안 보내는 토픽은 `(미발행)` |
| 일시정지/재개 | `⏸ 일시정지` / `▶ 재개` | 화면 갱신 멈춤/재개. 멈추면 제목 옆에 `· 일시정지됨` 표시 |

## 알아두기

- 메시지 타입(예: `geometry_msgs/msg/Twist`)이 표 위쪽에 표시됩니다.
- 배열은 `values[0]`, `values[1]` … 처럼 번호가 붙어 펼쳐집니다.
- 표가 길면(최대 400행) 패널 안에서 스크롤됩니다.
- 안내문: `토픽을 선택하세요` / `메시지 수신 대기…`(아직 안 들어옴) / `메시지 수신 대기… (토픽 미발행)`(그 토픽을 아무도 안 보냄).
