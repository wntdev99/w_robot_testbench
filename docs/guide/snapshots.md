# 스냅샷 — 화면 구성 저장·불러오기

> [← 사용 설명서 목차](../USER_GUIDE.md) · 관련: [워크스페이스 기본](workspace-basics.md)

힘들게 조립한 워크스페이스 화면을 **이름 붙여 저장**해두면, 다음에 클릭 한 번으로 똑같이 불러옵니다. (예: "모터 온도 테스트" 구성)

---

## 어디서 하나

워크스페이스 오른쪽 위 영역입니다.

```
[교체|추가]  [스냅샷 불러오기… ▼]  [💾 저장]  [🗑 ▼]
```

## 저장하기 (단계)

1. **`저장`** 버튼을 누릅니다. (작은 창이 뜸 — `스냅샷 저장`)
2. 이름을 입력합니다(예: `모터 온도 테스트`).
   - 새 이름이면 `새 스냅샷 '…' 생성`(초록)
   - 기존 이름이면 `기존 '…' 덮어쓰기`(주황)
3. **`저장`**(또는 `덮어쓰기`)을 누릅니다.
   → 왼쪽 메뉴 `워크스페이스` 아래에 그 이름이 나타납니다.

> 이미 불러온 스냅샷을 수정한 상태라면 버튼이 **`저장(덮어쓰기)`** 로 바뀝니다. 이름을 그대로 두면 덮어쓰고, 바꾸면 새로 저장됩니다.

## 불러오기

- **빠른 방법**: 왼쪽 메뉴(사이드바)에서 저장된 이름을 **클릭**.
- **드롭다운**: `스냅샷 불러오기…` 에서 선택.

불러올 때 모드를 고를 수 있습니다.

| 모드 | 동작 |
|---|---|
| **`교체`** | 지금 화면을 그 스냅샷으로 **바꿈** |
| **`추가`** | 지금 화면에 그 스냅샷을 **합쳐서 함께 표시** (드롭다운 라벨이 `스냅샷 합치기…` 로 바뀜) |

## 삭제하기

- 휴지통(**`🗑`**) 드롭다운에서 이름을 고르면 `스냅샷 '…' 삭제?` 확인 후 삭제됩니다.

## 알아두기

- 스냅샷에는 패널 종류·배치뿐 아니라 **각 패널의 설정값**(고른 토픽, 숨긴 그래프 선, 입력값 등)도 함께 저장됩니다.
- 대시보드의 `저장된 테스트 구성 (스냅샷)` 카드에서도 바로 열 수 있습니다 → [대시보드](dashboard.md).
