# 「텔레옵」 패널 — 로봇 수동 조종

> [← 사용 설명서 목차](../USER_GUIDE.md)

화면 패드·게임패드·키보드 세 가지 방법으로 로봇을 **직접 움직입니다**.

> ⚠️ **로봇이 실제로 움직입니다.** 주변에 사람·장애물이 없는지 먼저 확인하세요.
> 세 방법 모두 **누르고 있는 동안만** 명령이 나가고 **손을 떼면 즉시 멈추도록(데드맨)** 되어 있습니다.

---

## 공통

- 패널 위쪽에서 입력 방법을 고릅니다: **`화면패드`** / **`게임패드`** / **`키패드`**.
- 패널 아래에 항상 경고가 보입니다: `⚠ … 만 전송(데드맨). 떼면 즉시 정지. 컨트롤러 active 필요.`
- **컨트롤러가 활성(active)** 이어야 로봇이 실제로 반응합니다([컨트롤러 패널](panel-controllers.md) 참고).
- 현재 나가는 속도가 `x.. y.. z..` 숫자로 실시간 표시됩니다.

## 방법 A. 화면패드 (마우스)

- **원형 XY 패드**를 끌어 움직입니다: 위=`전진`, 아래=`후진`, 좌/우=옆 이동.
  손을 떼면 패드가 가운데로 돌아오고 로봇이 멈춥니다.
- **`회전(z)` 슬라이더**: 왼쪽=`좌회전`, 오른쪽=`우회전`. 떼면 가운데(정지)로 복귀.

## 방법 B. 게임패드 (USB 연결)

연결하면 패드 ID가 표시되고, 화면에 스틱·버튼 모양이 실시간으로 움직입니다. (안 잡히면 `게임패드 미감지 — 패드 연결 후 아무 버튼이나 누르세요`)

| 조작 | 동작 |
|---|---|
| **LT (왼쪽 뒤 트리거)** | **데드맨 — 누르고 있는 동안만 명령 전달.** 화면에 `주행 中 (LT)`(초록)/`LT 떼짐`(회색) |
| 왼쪽 스틱 (앞/뒤) | 전진·후진 |
| 오른쪽 스틱 (좌/우) | 제자리 회전 |
| **RB + 왼쪽 스틱(좌/우)** | 횡이동(게걸음) |

> 손가락의 미세한 떨림은 무시됩니다(데드존). LT를 떼면 즉시 정지합니다.

## 방법 C. 키패드 (키보드)

1. 패널의 **`여기를 클릭해 키 입력 활성화`** 영역을 클릭합니다(클릭해야 키가 먹습니다 → `키 입력 활성 (포커스 유지)`).
2. 아래 키를 **누르고 있는 동안** 움직입니다. 떼면 멈춥니다.

| 키 | 동작 |
|---|---|
| `I` | 전진 |
| `,` (쉼표) | 후진 |
| `J` / `L` | 좌회전 / 우회전 |
| **`Shift` + `J` / `L`** | 횡이동 왼쪽 / 오른쪽 (`횡 ←` / `횡 →`) |
| `K` | 정지 |

## 속도·대상 설정

| 항목 | 라벨 | 기본값 |
|---|---|---|
| 최대 직진 속도 | `최대 직진` | 0.4 m/s |
| 최대 회전 속도 | `최대 회전` | 0.8 rad/s |
| 명령 보낼 토픽 | `Topic` | `/swerve_controller/cmd_vel` |

## 알아두기

- 로봇이 반응하지 않으면: ① 컨트롤러가 active인지([컨트롤러 패널](panel-controllers.md)), ② 키패드면 입력 영역을 클릭했는지, ③ 게임패드면 LT를 누르고 있는지 확인하세요.
