# 「녹화」 패널 — 데이터를 파일(CSV)로 받기

> [← 사용 설명서 목차](../USER_GUIDE.md) · 관련: [토픽 안내](../topic-map.md)

선택한 토픽·진단·시스템 값을 **백엔드가 빠짐없이 기록**해 **CSV 파일**로 내려받습니다. 한 줄에 여러 값이 함께 들어가는 **Wide CSV**(엑셀에서 바로 열기 좋음) 형식입니다.

---

## 사용법 (단계)

1. `패널 추가` → **`녹화`**.
2. (선택) **`녹화 이름`** 을 입력합니다. 안 넣어도 됩니다.
3. 기록할 대상을 고릅니다 — 셋 중 **하나 이상**:
   - **`토픽 검색`** 칸으로 토픽을 찾아 **체크박스**로 선택 (선택 수가 `토픽 검색 (선택 N)` 에 표시)
   - **`diagnostics`** 체크 — 자가진단 값 포함
   - **`시스템`** 체크 — 서버 PC 상태 포함
4. **`● 녹화 시작`** 을 누릅니다.
   → `녹화 중` 과 함께 **현재 행 수 · 경과 시간(초)** 이 실시간 표시됩니다.
5. **`■ 정지 & CSV 저장`** 을 누르면 파일이 만들어집니다.
   → `저장됨: N행 · M열 — 다운로드` 링크로 받습니다.

## 화면 요소

| 요소 | 라벨 | 비고 |
|---|---|---|
| 이름 입력 | `녹화 이름 (선택)` | 비워도 됨 |
| 토픽 검색 | `토픽 검색 (선택 N)` | 입력으로 목록 좁힘, 체크로 선택 |
| 진단 포함 | `diagnostics` | 기본 켜짐 |
| 시스템 포함 | `시스템` | 기본 꺼짐 |
| 시작 | `● 녹화 시작` | 대상이 하나도 없으면 시작 안 됨 |
| 정지 | `■ 정지 & CSV 저장` | 정지하며 CSV 생성 |

## 알아두기

- 아래 **`저장된 녹화`** 목록에서 이전 파일들도 다시 받을 수 있습니다(파일명 · 행 수 · 다운로드).
- 토픽을 하나도 안 고르고 `diagnostics`/`시스템`도 끄면 녹화가 시작되지 않습니다.
- 어떤 토픽을 녹화할지는 [토픽 안내](../topic-map.md)를 참고하세요.
