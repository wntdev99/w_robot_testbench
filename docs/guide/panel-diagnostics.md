# 「Diagnostics」 패널 — 로봇 자가진단(모터 온도·전류 등) 보기

> [← 사용 설명서 목차](../USER_GUIDE.md) · 관련: [토픽 안내](../topic-map.md)

로봇이 스스로 내보내는 **자가진단 정보**(`/diagnostics`)를 그래프/표로 봅니다. 모터 온도·전류·전압처럼 기기별로 쏟아지는 점검값을 **항목별 또는 기기별**로 묶어 보여줍니다.

---

## 사용법 (단계)

1. `패널 추가` → **`Diagnostics`**.
2. 묶는 기준(축)을 고릅니다.
   - **`항목별`** = `temperature`, `voltage` 같은 **점검 항목** 기준으로 묶기
   - **`기기별`** = `조향 FL (can2:11)` 같은 **하드웨어** 기준으로 묶기
3. 드롭다운(`항목 선택…` 또는 `기기 선택…`)에서 하나를 고릅니다.
4. 나타난 **필드 칩**을 클릭해 볼 값을 켭니다.
5. **`그래프` / `표`** 로 표시 방식을 바꿉니다.

## 화면 요소

| 요소 | 라벨 | 동작 |
|---|---|---|
| 뷰 토글 | `그래프` / `표` | 그래프 ↔ 표 전환 (시간창은 2분 고정) |
| 축 토글 | `항목별` / `기기별` | 묶는 기준 전환 |
| 카테고리 드롭다운 | `항목 선택…` / `기기 선택…` | 볼 묶음 선택 |
| 필드 칩 | 기기명 또는 항목명 | 클릭으로 켜기/끄기 |

### 기기 이름 표기 예 (조향 모터)

| 화면 표기 | 의미 |
|---|---|
| `조향 FL (can2:11)` | 앞왼쪽(Front-Left) 조향 |
| `조향 FR (can2:12)` | 앞오른쪽 |
| `조향 RL (can2:13)` | 뒤왼쪽 |
| `조향 RR (can2:14)` | 뒤오른쪽 |

## 알아두기

- 안내문 `/diagnostics 데이터 없음 (드라이버 기동 필요)` 가 뜨면, 진단을 내보내는 노드가 아직 안 켜진 것입니다 → [런치 패널](panel-launch.md)로 관련 기능을 먼저 켜세요.
- `항목별`로 봤을 때 `temperature` 묶음이 있으면 자동으로 먼저 선택됩니다.
