# 「카메라」 패널 — 카메라 영상 실시간 보기

> [← 사용 설명서 목차](../USER_GUIDE.md) · 관련: [토픽 안내](../topic-map.md)

이미지 토픽을 골라 **카메라 영상을 실시간**으로 봅니다. 컬러·깊이(Depth) 영상 모두 지원합니다.

---

## 사용법

1. `패널 추가` → **`카메라`**.
2. **`이미지 토픽…`** 드롭다운에서 카메라 토픽을 고릅니다.
   → 영상이 실시간으로 나오면 정상입니다.

> 로봇에는 카메라가 여러 대 있습니다(바닥 4방향·전방·핸드아이). 각각 어떤 토픽인지는 [토픽 안내 §3](../topic-map.md)을 참고하세요.

## 화면 요소

| 요소 | 라벨 | 동작 |
|---|---|---|
| 토픽 드롭다운 | `이미지 토픽…` | 볼 카메라 선택. 압축 토픽은 `(압축)` 표시. 열 때 목록 자동 갱신 |
| 표시 토글 | `표시` / `구독만` | 보통은 `표시`. `구독만`은 화면에 안 그리고 수신 부하만 거는 **로드 테스트용** |

## 안내문(상태 메시지)으로 상황 읽기

| 안내문 | 의미·조치 |
|---|---|
| `이미지 토픽을 선택하세요` | 아직 토픽을 안 골랐음 |
| `(발행 중인 이미지 토픽 없음)` | 카메라 노드가 안 켜짐 → [런치 패널](panel-launch.md)로 카메라 기능 켜기 |
| `토픽 미발행 — … 자동 갱신되어 표시됩니다` | 그 카메라가 아직 영상을 안 보냄. 켠 뒤 드롭다운을 다시 열면 갱신 |
| `동시 카메라 스트리밍 제한 초과` | 카메라 패널이 너무 많음 → 다른 카메라 패널을 닫기 |
| `프레임 수신 대기…` | 곧 영상이 들어올 예정 |
| `서버에 cv2/cv_bridge 없음` | 서버에 영상 변환 기능이 없음 → 담당자 문의 |

## 알아두기

- 영상 끊김·지연을 숫자로 점검하려면, 같은 카메라의 **수신 Hz 토픽**을 [플롯 패널](panel-plot.md)로 보세요([토픽 안내 §3](../topic-map.md)).
