# 「플롯」 패널 — 센서·시스템 값 그래프/표로 보기

> [← 사용 설명서 목차](../USER_GUIDE.md) · 관련: [토픽 안내](../topic-map.md)

로봇이 내보내는 데이터(토픽)나 서버 PC 상태(시스템)를 **실시간 꺾은선그래프 또는 숫자표**로 봅니다.

---

## 화면 구성

```
┌─ 플롯 ───────────────────────────── [그래프|표] [10초▼] ─┐
│ [토픽 | 시스템]   [토픽… ▼]                              │
│ ( position.x )( position.y )( velocity )  ← 필드 칩      │
│ ┌──────────────────────────────────────────────────┐    │
│ │            ╱╲    ╱╲                                │    │
│ │         ╱╲╱  ╲╱╲╱  ╲                               │    │
│ └──────────────────────────────────────────────────┘    │
└──────────────────────────────────────────────────────────┘
```

## 사용법 (단계)

1. `패널 추가` → **`플롯`**.
2. 데이터 소스를 고릅니다.
   - **`토픽`** = 로봇이 내보내는 데이터 → 오른쪽 **`토픽…`** 드롭다운에서 토픽 선택
   - **`시스템`** = 서버 PC 상태 → **`카테고리…`** 드롭다운에서 선택
3. 토픽/카테고리를 고르면 그 안의 **숫자 항목들이 칩(둥근 버튼)** 으로 나타납니다.
4. 보고 싶은 칩을 **클릭해서 켭니다**(다시 누르면 끔). → 켠 항목만 그래프에 그려집니다.

## 화면 요소

| 요소 | 라벨 | 동작 |
|---|---|---|
| 뷰 토글 | `그래프` / `표` | 꺾은선그래프 ↔ 숫자표 전환 |
| 시간창 (그래프일 때) | `10초` `30초` `1분` `2분` `5분` `10분` | 그래프에 보일 과거 데이터 길이 |
| 소스 토글 | `토픽` / `시스템` | 데이터 출처 전환 |
| 토픽 드롭다운 | `토픽…` | 토픽 선택. 안 보내는 토픽은 `(미발행)` 표시 |
| 카테고리 드롭다운 | `카테고리…` | 시스템 분류 선택(아래 표) |
| 필드 칩 | 항목명 | 클릭으로 개별 항목 켜기/끄기 |

### 시스템 카테고리 종류

`CPU` · `메모리` · `온도` · `네트워크(처리량)` · `지연(latency ms)` · `연결상태`

## 알아두기

- **범례를 클릭**하면 그 선만 잠시 숨길 수 있고, 이 숨김 상태는 스냅샷에 함께 저장됩니다.
- 그래프가 비어 있으면: 안내문(`토픽을 선택하세요` / `필드를 선택하세요` / `데이터 수신 대기…` / `플롯 가능한 수치 필드 없음`)을 확인하세요.
- 그래도 안 그려지면 상태 막대의 `zenoh`가 초록(`●`)인지 확인 — 회색이면 데이터가 안 들어오는 것입니다.
- 어떤 토픽을 골라야 할지 모르겠으면 [토픽 안내](../topic-map.md)를 참고하세요.
