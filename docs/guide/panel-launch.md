# 「런치」 패널 — 로봇 기능 켜고 끄기

> [← 사용 설명서 목차](../USER_GUIDE.md)

설치된 **런치 파일**(로봇 기능 묶음)을 찾아 **실행·종료**합니다. 서버(202)와 컨트롤러(201) 양쪽을 다룹니다.

> ⚠️ **이 패널은 로봇/노드를 실제로 켜고 끕니다.** 모터·주행 런치를 켜면 **로봇이 움직일 수 있습니다.** 시작 전 주변 안전을 반드시 확인하세요.

---

## 사용법 (단계)

1. `패널 추가` → **`런치`**.
2. 위쪽에서 대상 머신을 고릅니다: **`서버(202)`** 또는 **`컨트롤러(201)`**.
3. **`런치 파일 검색…`** 칸에 이름 일부를 입력해 목록을 좁힙니다.
4. 원하는 런치의 **`선택`** 을 누릅니다. (필요하면 **인자** 입력 — 아래 참고)
   → 패널에 그 런치가 고정됩니다.
5. **`실행`** 을 누릅니다.
   → 같은 런치가 이미 돌고 있으면 **확인 창**이 뜹니다(아래).
6. 다른 런치를 고르려면 **`수정`** 을 눌러 검색으로 돌아갑니다.
7. 실행 중인 항목은 **`종료`** 로 끕니다.

## 인자(선택) 입력

- 형식은 반드시 **`이름:=값`** 입니다. 예) `use_velocity_smoother:=false ekf_enable:=false`
- 형식이 틀리면 빨간 안내가 뜨고 `선택`이 막힙니다:
  - `'…': 'name:=value' 형식이어야 합니다`
  - `'…': 인자 이름이 비어 있습니다`

## 실행 전 확인 창

이미 같은/비슷한 런치가 돌고 있을 때 **`런치 실행 전 확인`** 창이 뜹니다.

| 버튼 | 동작 |
|---|---|
| `취소` | 실행 안 함 |
| `그대로 실행` | 기존 것을 둔 채 새로 실행 |
| `선택 종료 후 실행` | 충돌하는 항목을 끄고 새로 실행 (끌 항목을 체크) |

> `⚠ 같은 런치가 이미 실행 중입니다(충돌). 종료 후 재실행을 권장합니다.` 문구가 보이면 **`선택 종료 후 실행`** 을 권장합니다.

## 상태 색으로 읽기

| 색 | 상태 | 뜻 |
|---|---|---|
| 초록 | `running` | testbench가 켜서 돌고 있음 |
| 파랑 | `external` | 다른 경로로 이미 돌던 것 |
| 주황 | `starting` / `stopping` | 켜지는/꺼지는 중 |
| 빨강 | `failed` | 실패 |

## 알아두기

- 컨트롤러(201) 대상인데 **`201 SSH 실패 — 종료 명령 미전달…`** 이 뜨면, 201 원격 연결이 막힌 것입니다(상태 막대 `201 SSH✗`). 담당자에게 SSH 설정을 요청하세요.
- 지금 무엇이 돌고 있는지는 워크스페이스 맨 위 **`실행 중 런치`** 줄의 **`파악`** 버튼으로 확인합니다([워크스페이스 기본](workspace-basics.md)).
- 여러 런치를 묶어 한 번에 켜고 끄려면 **프로파일** 버튼(`▶`/`■`)을 사용합니다.
