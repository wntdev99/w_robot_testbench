# 「네비게이션」 패널 — 지도 위에서 목표 지점으로 주행

> [← 사용 설명서 목차](../USER_GUIDE.md)

RViz풍 2D 지도 화면입니다. 지도·장애물·로봇 위치를 보고, **초기 위치 지정**과 **목표 지점 주행**을 시킵니다.

> ⚠️ `Nav Goal`을 찍으면 **로봇이 스스로 움직입니다.** 주변 안전을 먼저 확인하고, 멈추려면 **`주행취소`** 를 사용하세요.

---

## 화면 구성

```
┌─ 네비게이션 ──────────────────────────────────────────┐
│ [2D Pose] [Nav Goal] [주행취소]   ☑scan ☑footprint ☑pose [맵] │
│ ┌──────────────────────────────────────────────────┐  │
│ │              🔴 (scan 점들)                        │  │
│ │        🟢➤ (로봇 위치·방향)                        │  │
│ │              🔵 (footprint)                        │  │
│ └──────────────────────────────────────────────────┘  │
│ 드래그=이동 · 휠=확대 · 🟢로봇 🔵footprint 🔴scan       │
└────────────────────────────────────────────────────────┘
```

## 지도 보기

| 조작 | 동작 |
|---|---|
| 마우스 드래그 | 지도 이동(pan) |
| 마우스 휠 | 확대/축소(zoom) |
| `맵` 버튼 | 지도 다시 불러오고 화면 맞춤 초기화 |

표시 켜고 끄기(체크박스): **`scan`**(빨강 점, 라이다) · **`footprint`**(파랑, 로봇 외형) · **`pose`**(초록, 로봇 위치·방향).

## 위치·목표 지정 (단계)

**초기 위치 알려주기** — 로봇이 자기 위치를 잘못 알 때
1. **`2D Pose`** 버튼을 눌러 켭니다(초록색이 됨).
2. 지도에서 **실제 로봇 위치를 클릭한 채 방향으로 드래그** 후 뗍니다.
   → 그 위치·방향이 로봇에 전달됩니다. (작업 후 모드는 자동 해제)

**목표 지점으로 보내기**
1. **`Nav Goal`** 버튼을 눌러 켭니다(파란색이 됨).
2. 지도에서 **목표 지점을 클릭한 채 바라볼 방향으로 드래그** 후 뗍니다.
   → 로봇이 그 지점으로 주행을 시작합니다.

**멈추기**
- **`주행취소`** 를 누르면 진행 중인 주행이 취소됩니다(`주행 취소 (N건)` 표시).

## 알아두기

- 안내문 `맵 없음 (map_server 미기동)` 이 뜨면 지도 서버가 안 켜진 것 → [런치 패널](panel-launch.md)로 내비게이션을 먼저 켜세요.
- `nav 의존성 없음(tf2/cv2)` 은 서버에 필요한 기능이 없는 것 → 담당자 문의.
- 드래그 방향이 곧 로봇이 **바라볼 방향**입니다. 클릭만 하지 말고 살짝 끌어 방향까지 정하세요.
