# 「컨트롤러」 패널 — 모터 제어기 켜고 끄기

> [← 사용 설명서 목차](../USER_GUIDE.md)

`controller_manager`가 관리하는 **제어기(controller) 목록**을 보고, 각각을 **활성/비활성**으로 전환합니다. (예: 스워브 주행 제어기, 조인트 상태 방송기 등)

> ⚠️ 이 패널은 **모터 제어와 직접 연관**됩니다. 활성화하면 해당 제어기가 모터 명령을 받기 시작할 수 있으니, 주변 안전을 먼저 확인하세요.

---

## 사용법

1. `패널 추가` → **`컨트롤러`**.
   → 현재 제어기 목록이 나오고, 3초마다 자동 갱신됩니다.
2. 각 행에는 **제어기 이름 · 종류 · 현재 상태**가 표시됩니다.
3. 오른쪽의 **`활성` / `비활성`** 버튼으로 상태를 전환합니다.
   → 잠시 후 목록이 자동으로 새로고침되어 바뀐 상태가 반영됩니다.

## 화면 요소

| 요소 | 표시/라벨 | 의미 |
|---|---|---|
| 상태 | `active` 등 | 활성=초록, 비활성=회색 |
| 전환 버튼 | `활성` / `비활성` | 클릭으로 해당 제어기 켜기/끄기 |
| 안내문 | `컨트롤러 없음 (컨트롤러 기동 필요)` | 제어기를 못 찾음 → 먼저 관련 런치를 켜야 함 |

## 알아두기

- `joint_state_broadcaster`(조인트 상태 방송기)는 **전환 버튼이 없습니다**(읽기 전용).
- 제어기가 하나도 안 보이면, 제어 관련 노드가 아직 안 켜진 것입니다 → [런치 패널](panel-launch.md)을 먼저 사용하세요.
