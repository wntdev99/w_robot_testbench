# 「명령」 패널 — 토픽 발행 / 서비스 호출 / 액션 보내기 (고급)

> [← 사용 설명서 목차](../USER_GUIDE.md) · 관련: [토픽 안내](../topic-map.md) · [서비스 안내](../service-map.md)

토픽에 메시지를 **publish(발행)** 하거나, **service(서비스) 호출**, **action(액션) 목표 전송**을 하는 패널입니다. 메시지 종류에 맞는 입력 폼이 **자동으로 생성**됩니다.

> ⚠️ **고급 기능입니다.** 명령에 따라 로봇이 움직이거나 설정이 바뀔 수 있습니다. 무엇을 보내는지 알 때만 사용하세요. (이 패널은 확인 창 없이 바로 전송됩니다)

---

## 모드 고르기

패널 위쪽에서 **`토픽`**(publish) / **`서비스`**(call) / **`액션`**(action) 중 하나를 고릅니다.

| 모드 | 무엇을 | 실행 버튼 |
|---|---|---|
| `토픽` | 토픽에 메시지 발행 | `보내기 (publish)` |
| `서비스` | 서비스 요청→응답 | `호출 (call)` |
| `액션` | 목표 전송→진행/결과 | `goal 전송` |

## 사용법 (공통)

1. 모드를 고릅니다.
2. 드롭다운에서 대상을 고릅니다(`토픽…` / `서비스…` / `액션…`).
   → 그 메시지의 **항목별 입력 폼**이 자동으로 나타납니다.
3. 각 항목을 채웁니다(아래 입력 방식 표).
4. 실행 버튼을 누릅니다.

## 항목 입력 방식

| 항목 종류 | 입력 방법 | 예 |
|---|---|---|
| 숫자 | 숫자 입력칸 | `3.14` |
| 참/거짓 | 체크박스 | ☑ / ☐ |
| 글자 | 글자 입력칸 | 자유 입력 |
| 목록(배열) | 쉼표나 대괄호로 | `1, 2, 3` 또는 `[1,2,3]` |

### JSON 직접 입력

복잡한(중첩) 메시지는 **`JSON 직접 입력 (중첩 배열/복합/타입 미상)`** 토글을 켜고 JSON으로 직접 적습니다. 예: `{"data": [1, 2, 3]}`. 형식이 틀리면 `JSON 파싱 오류` 가 표시됩니다.

## 모드별 결과 보기

- **토픽**: 성공 시 `publish ✓ (시각)`.
- **서비스**: `응답: …` 으로 결과 표시.
- **액션**: `goal 수락 (…)` → 진행 중 `feedback: …` → 끝나면 `result(status …): …`. 끝나기 전엔 **`취소`** 버튼으로 중단 가능.
